# Portfolio Rafif
Personal portfolio website — React 18 + TypeScript + Vite + Tailwind CSS + React Router.
See `CLAUDE.md`, `PRD.md`, `ARCHITECTURE.md`, `DESIGN.md` in the project root for spec & working principles.

## Setup

```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
